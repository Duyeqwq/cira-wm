Geometry In The Loop

01 / RELATE

Source-aware interaction

Local robot-to-scene relations preserve arm identity and palm/finger roles on the original PointWorld representation.

02 / PREDICT

Predicted geometry feedback

A recurrent point state updates relation queries using predicted scene positions while retaining the original prediction heads.

03 / CARRY

Persistent constraints

Learned references and release strength carry interaction information across the prediction horizon.

The model is conditioned on known future robot trajectories. Geometry feedback is not a claim of causal identification or a certified robot controller.
